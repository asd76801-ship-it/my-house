카카오 지도 JavaScript 키 입력

  1. developers.kakao.com에서 앱 생성 → 앱 키의 JavaScript 키 복사
  2. 플랫폼 → Web → 사이트 도메인에 http://localhost:8000 등록
  3. 카카오맵 사용 설정을 켜고, 이 파일이 있는 폴더에서 python3 -m http.server 8000 실행 후 http://localhost:8000/kakao_map.html 접속
키는 이 브라우저(localStorage)에만 저장됩니다.
